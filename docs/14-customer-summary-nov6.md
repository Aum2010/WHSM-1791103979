# สรุปการอัปเดตระบบ WH-RM รอบ 6 พ.ย. 2569

รอบนี้นำหน้าจอชุดใหม่ที่ทีม UI ส่งมาวันที่ 6 พ.ย. ขึ้นระบบ และทำตามคำตอบของท่านเมื่อวันที่ 6 พ.ย.

## สิ่งที่จะเห็นในแต่ละฝ่าย

### ฝ่ายคลังและฝ่ายขนส่ง (WH13 / LG02)
- **ของที่อยู่บนรถระหว่างโอนถูกกันยอดไว้:** เมื่อกด "ยืนยันโหลดและรถออก" ยอดคงเหลือที่จ่ายได้ของคลังต้นทางจะลดลงทันที เพื่อไม่ให้ของชิ้นเดียวกันถูกจ่ายซ้ำ
  - ใน Stock Card ต้นทางจะเห็นแถว "กันยอดระหว่างขนส่ง"
  - เมื่อปลายทางรับเข้า ระบบตัดยอดจริงตามจำนวนที่รับ และลดยอดที่กันไว้ลงเท่ากัน
  - ถ้าปิดใบหรือยกเลิกใบ ยอดที่กันไว้จะคืนกลับ
- **หลักฐานการส่งมอบ (POD):** ใบส่งสินค้าขาย (SO / EO) บันทึกลายเซ็น รูปถ่าย และจำนวนที่ลูกค้ารับได้ ข้อมูลนี้เห็นตรงกันทุกเครื่อง
- **WH13:** มีหน้าจอใหม่ เช่น สินค้า 2 หน่วย (กิโลกรัม / แพค), ทะเบียนคลัง และ KPI แบบใหม่ ตามที่ทีม UI ออกแบบ

### ฝ่ายขาย (BD02)
- **ทะเบียนพนักงานขาย เป้ายอดขาย และเขตการขาย:** ใช้งานได้จริงและเห็นตรงกันทุกเครื่อง เปิดดูได้เฉพาะผู้มีสิทธิ์ฝ่ายขาย
- **ใบเสนอราคา:**
  - เลือกสกุลเงิน ใส่ส่วนลด โปรโมชัน และของแถมได้
  - VAT คิดจากราคาก่อน VAT แล้วบวก 7% ท้ายใบ
- **คำสั่งซื้อใหม่ต้องรอหัวหน้า BD อนุมัติก่อนส่งเข้าคลัง** เหมือนเดิม
- **ตารางคอมมิชชันซ่อนไว้ก่อน** จนกว่าท่านจะยืนยันสูตรคำนวณ

### ฝ่าย QA (QA_DCC_02 ควบคุมเอกสาร)
- **ใช้บัญชีเดียวกับระบบหลัก:** login ด้วยรหัสพนักงานและรหัสผ่านเดิม ไม่ต้องจำรหัสแยกของ DCC
- **ผู้อนุมัติเอกสาร QA** คือ QA manager และผู้ดูแลระบบ
- **จัดการผู้ใช้ รหัส และผู้อนุมัติที่หน้า "จัดการผู้ใช้" (ผู้ดูแลระบบ):** ในหน้า DCC แก้ได้เฉพาะตำแหน่งและหน่วยงาน
- **ขั้นตอนควบคุมเอกสารครบวงจร:** ขอฟอร์ม → ออกแบบ → อนุมัติ → จ่ายสำเนาให้แต่ละหน้า → เรียกคืน / ทำลาย ตามที่ทีม UI ออกแบบ

### ฝ่ายผลิต
- **หน้า PD01 เป็นเมนูหลักของฝ่ายผลิต:** กดเข้า Preparing, Packing และวางแผนผลิตได้ ตัวเลขสรุปจะแสดงเมื่อเชื่อมข้อมูลจริง
- **หน้า Packing login ด้วยบัญชีของตนเอง:** รายการสำคัญ เช่น ปลดล็อกน้ำหนักภาชนะ แก้หรือลบรายการ และบันทึกน้ำหนักที่หลุดเกณฑ์ ต้องยืนยันด้วยบัญชีที่มีสิทธิ์
  - หัวหน้า (PD supervisor): ทำได้ทุกรายการ
  - PD-Leader: ปลดล็อกน้ำหนักภาชนะและเปิดโหมดกรอกน้ำหนักเองได้
  - QC Final inspection: บันทึกน้ำหนักที่หลุดเกณฑ์ได้
  - พนักงานทั่วไป: ทำรายการปกติได้ แต่ทำรายการที่ต้องยืนยันสิทธิ์ไม่ได้
- **ข้อมูลฝ่ายผลิตเห็นตรงกันทุกเครื่อง:** ตั้งค่า บรรจุภัณฑ์ รายการเตรียมวัตถุดิบ และข้อมูลวางแผนผลิต

### ผู้ดูแลระบบ
- **หน้าจัดการผู้ใช้มีช่องสิทธิ์ใหม่ "ควบคุมเอกสาร (DCC)":**
  - พนักงานที่เคยเปิดหน้า DCC ได้ ยังเปิดได้เหมือนเดิม
  - ผู้อนุมัติเอกสารต้องตั้งเป็นระดับ "อนุมัติ"
- **ตั้งสิทธิ์ฝ่ายผลิตที่ช่อง "ผลิต":**
  - ระดับ "อนุมัติ" = PD supervisor
  - ระดับ "ใช้งาน" = พนักงานทั่วไป
  - PD-Leader และ QC: ตั้งรหัสบัตรหรือ "ชื่อในหน้าจอ" เป็น PD004 / PD007

## ความปลอดภัย
- **รหัสผ่านที่เคยฝังในหน้าจอถูกลบออกแล้ว** (หน้า Packing และ DCC) ทุกการ login ตรวจที่ server
- **เอกสารสรุป BD02 (ไฟล์ "75% BD02") มีรหัสผ่านของฝ่ายขายเขียนไว้** โปรดอย่าส่งต่อไฟล์นี้ และแนะนำให้เปลี่ยนรหัสของบัญชีเหล่านั้น

## ยังไม่ได้ทำในรอบนี้
- **ใบแจ้งหนี้ / ใบเสร็จของฝ่ายขาย:** ยังคิด VAT แบบรวมในยอด ไม่ตรงกับที่ท่านตอบ (ราคาไม่รวม VAT) จะแก้ในรอบถัดไป
- **ราคาเริ่มต้นจากใบรายการสินค้า 5 รูป:** รอจับคู่ชื่อสินค้าในรูปกับรหัสสินค้าในระบบก่อน
- **การเก็บประวัติ Audit 1 ปีแล้ว export:** ยังไม่ได้ทำ
- **หน้าจัดซื้อ (PR08):** ยังไม่ขึ้นระบบ เพราะยังเป็นข้อมูลตัวอย่าง
- **ตารางคอมมิชชัน:** รอท่านยืนยันสูตร
