    ส่วน E

    บัตรสรุป ติดไว้หน้าเครื่อง

    ทำคล่องแล้วดูแค่นี้ก็พอ

    พนักงานชั่ง (V4)

    1. Login V4 ด้วยบัตร หรือรหัสบัตร + PIN
    2. กรอกข้อมูลเที่ยวรถ
    3. เปิดใช้งาน แล้วยืนยันตัวตนเครื่องชั่ง
    4. กดเชื่อมต่อเครื่องชั่ง
    5. เลือกสินค้า ใส่ Lot และ BBF/EXP
    6. วางภาชนะเปล่า กดหักภาชนะ
    7. วางของ รอ 10 วิ (หรือกดชั่งน้ำหนัก)
    8. ครบแล้วกดบันทึก พิมพ์ฉลาก
    9. ประวัติการชั่ง → นำส่ง WMS
    10. เลิกงานกดปิด Session

    พนักงานคลัง (WH13)

    1. Login ด้วยรหัสบัตร + PIN
    2. รับเข้าสินค้า/QA → เลือกคลังปลายทาง
    3. Auto Weighing → เลือก Report → นำเข้า
    4. เลือกประเภทการตรวจ ติ๊ก แล้วสร้าง RO
    5. รอ QA ตรวจ (สถานะ พร้อมอนุมัติ)
    6. ติ๊ก RO → ยืนยันรับเข้าคลัง (หัวหน้าทีม)
    7. เช็ก Stock Card

    QA (QA Incoming)

    1. เปิดการ์ด QA Incoming
    2. เลือก QA Issue จาก WH13 → เลือกรายการนี้
    3. กรอกผลตรวจแต่ละหัวข้อ
    4. ผลการตัดสิน: ACCEPT หรือ REJECT
    5. บันทึกผลตรวจรับ · ทำจนครบทุกรายการ

    ผู้ดูแลระบบ

    1. หน้ารวม → จัดการผู้ใช้
    2. นำเข้า Excel (Authorized list)
    3. ตรวจ Template แล้วกดนำเข้า
    4. ตั้งสิทธิ์ที่ตารางสิทธิ์
    5. ลืม PIN: แก้ไข → ใส่รหัสใหม่
    6. ลาออก: เปลี่ยนสถานะเป็นปิด

    กดที่ใดก็ได้ หรือกด Esc เพื่อปิด
