# เริ่มใช้งานจริงจากฐานข้อมูลสะอาด

สำหรับทีมที่ดูแล server · ทำเมื่อพร้อมเปิดใช้งานจริง ขั้นตอนนี้ลบข้อมูลทดสอบถาวร

## สิ่งที่หายและสิ่งที่ต้องเตรียม

| ข้อมูล | หลังเริ่มใหม่ | ต้องทำ |
|---|---|---|
| Stock, ใบโอน, รับเข้า, เบิก, ออเดอร์, ใบเสนอราคา | ว่าง | นำเข้ายอดตั้งต้น (ขั้น 5) |
| บัญชีผู้ใช้ | เหลือผู้ดูแลจาก `WHRM_ADMIN_*` | Import Authorized list ที่หน้าจัดการผู้ใช้ |
| รายการสินค้า | สร้างจาก Seed เมื่อเปิด DBV2.0 ครั้งแรก | ตรวจกับรายการจริง |
| หน่วยนับ, ลูกค้า, Supplier, โลโก้ฟอร์ม | ค่าเริ่มต้นหรือว่าง | Export จากระบบเดิมก่อนล้าง แล้วนำเข้าหรือกรอกใหม่ |

## ขั้นตอน

1. **ประกาศหยุดใช้งาน** ให้ทุกเครื่องปิดหน้าเว็บ และยืนยันว่าเครื่องอื่นไม่ได้เปิดค้าง
2. **สำรองฐานข้อมูล** และทดสอบเปิดไฟล์สำรอง

   ```sh
   pg_dump --format=custom --file=whrm-before-go-live.dump "$DATABASE_URL"
   ```

3. **สร้างฐานข้อมูลใหม่** แล้วชี้ `DATABASE_URL` ไปที่ฐานใหม่ · แนะนำวิธีนี้แทนการลบข้อมูลในฐานเดิม เพราะย้อนกลับได้ทันที · backend สร้างตารางให้เองตอนเริ่มทำงาน
4. **ล้างข้อมูลในทุกเครื่อง** (สำคัญ) เบราว์เซอร์ยังเก็บข้อมูลเดิมใน localStorage และอาจส่งกลับขึ้น server · เปลี่ยน URL ของระบบ หรือล้างข้อมูลเว็บไซต์ของระบบในทุกเครื่องก่อนเปิดใช้งาน
5. **ตั้งค่าตั้งต้น:** login ด้วยผู้ดูแล → Import Authorized list → เปิด DBV2.0 ตรวจสินค้า → ตั้งหน่วยนับ → เพิ่มลูกค้า → นำเข้ายอดสต็อกจากการนับจริง
6. **ตรวจรับ:** ทำรายการจริงอย่างน้อย 1 รอบ ได้แก่ รับเข้า, โอน, เบิก, จ่าย และออเดอร์ BD02 แล้วเทียบยอดกับของจริง

## ย้อนกลับ

ชี้ `DATABASE_URL` กลับฐานเดิม แล้ว restart backend · ถ้าฐานเดิมเสียหาย ใช้ `pg_restore` จากไฟล์ขั้น 2

## ยังไม่มีเครื่องมือ

- **นำเข้ายอดสต็อกตั้งต้น:** ยังไม่มีหน้าหรือสคริปต์สำหรับงานนี้ ต้องรอลูกค้าเลือกวิธีตั้งยอด
- **ล้างข้อมูลในเครื่องอัตโนมัติ:** ตอนนี้ต้องทำทีละเครื่อง

## สิ่งที่ซ่อนหรือจำกัดไว้แล้วสำหรับใช้งานจริง

ทำผ่าน hotfix ตอน build ใน `whrm-frontend/scripts/hotfixes.mjs` (ควรแจ้งลูกค้าแก้ต้นทาง)

- **เฉพาะผู้ดูแลระบบ:** Hard Reset ของ DBV2.0, ล้างข้อมูลทั้งหมดของ V4 และ Preparing, Reset Stock Card, คำสั่งล้างข้อมูลทดสอบของ WH13
- **ซ่อน:** ปุ่ม Reset ข้อมูลทดสอบของ BD02, ปุ่ม Seed ใน Info Center, แถวตัวอย่างใน QA Deviation
- **LG02:** เอาใบงานตัวอย่างออก และซ่อน Dashboard, Planning, Dispatch, Track & Trace, DC & Dock, Fleet, Carriers, Exceptions, Reports, Analytics จนกว่าจะต่อข้อมูลจริง
