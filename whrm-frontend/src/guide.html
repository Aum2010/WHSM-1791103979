1. ระบบทำงานอย่างไร

ของไหลผ่านโรงงานตามลำดับนี้ — แต่ละกล่องคือหน้าจอในระบบ งานที่ทำเสร็จในหน้าหนึ่งจะไปโผล่ที่หน้าถัดไป แม้เปิดคนละเครื่อง

🚚 รถวัตถุดิบเข้า→⚖️ V4 ชั่ง→📦 WH13 รับเข้าคลัง→🔬 QA ตรวจ→✅ เข้าสต็อก
📦 สต็อก→🏭 ฝ่ายผลิต เตรียม / เสียบ / บรรจุ→🚚 FGT ส่งสินค้าเข้าคลัง→✅ QA อนุมัติ
🛒 BD02 ฝ่ายขายสั่ง→📥 WH13 ศูนย์รับข้อมูล→🚛 WH13 ศูนย์จ่ายออก→✅ ส่งลูกค้า

ข้อมูลกลางที่ทุกหน้าใช้: DBV2.0 (รายการสินค้า หมวดหมู่ ผู้ขาย ลูกค้า) · เมื่อพบปัญหาคุณภาพ QA Deviation สั่ง Hold ของในคลังได้

2. ก่อนเริ่ม (ทำครั้งเดียว)

  1. Login เข้าระบบ ที่หน้า login (ผู้ดูแลแจกชื่อผู้ใช้ให้) — เปิดหน้าไหนก่อน login ระบบจะพามาหน้า login เอง
  2. ดูป้ายมุมขวาล่าง ทุกหน้าต้องเป็นสีเขียว ● Server · ชื่อคุณ แปลว่าต่อกับระบบกลางแล้ว
  3. ระบบใหม่ / ล้างข้อมูลมา: เปิด DBV2.0 หนึ่งครั้ง เพื่อส่งรายการสินค้า (~500 รายการ) ขึ้นระบบกลาง — หลังจากนั้นทุกเครื่องได้รายการสินค้าครบ
  4. เปิดแต่ละหน้าใน แท็บใหม่ (กดลิงก์ในหน้ารวม) — เปิดค้างไว้ได้หลายแท็บพร้อมกัน
อยากลองเหมือนมีหลายเครื่อง? เปิด browser 2 ยี่ห้อ (เช่น Chrome กับ Edge) แล้ว login ทั้งคู่ — เท่ากับ 2 เครื่อง

3. Login มี 2 ชั้น (สำคัญ — คนงงบ่อยที่สุด)

ผู้ดูแลเพิ่ม/แก้ผู้ใช้ได้ที่หน้ารวม
ชั้นที่ 2: Login ในหน้าจอบางหน้ามีระบบ login ของตัวเอง (ทีมออกแบบหน้าจอทำไว้) ใช้ตอนกดปุ่มสำคัญ เช่น อนุมัติ ส่ง FGT · บางปุ่ม ถามรหัสทุกครั้ง (ตั้งใจ)

5. ลองทำตามทีละขั้น

เริ่มจาก A ก่อน — เป็นเส้นทางหลักของระบบ ส่วนอื่นทำทีหลังได้

A. รับวัตถุดิบเข้าคลัง (V4 → WH13) — เริ่มที่นี่

ที่ V4 (พนักงานชั่ง)

  1. เปิด V4 → เมนู บันทึกการชั่ง → กด สร้างชุดใหม่
  2. เลือกประเภท รับ, ทะเบียนรถ, ผู้ขนส่ง แล้วเลือก สินค้า
  3. กด เชื่อมต่อ เครื่องชั่ง (ไม่มีเครื่องชั่งจริง: ใช้โหมด Manual / ปุ่ม 🤖 Demo Bot ถ้าเปิดไว้) → เซ็ตศูนย์ → วางของ → กด ชั่งน้ำหนัก ทำซ้ำได้หลายรายการ (รายการขึ้นในตะกร้าด้านล่าง)
  4. กด 💾 บันทึก ทั้งหมด — ระบบพิมพ์ label และพาไปหน้าประวัติ
  5. ที่หน้า ประวัติการชั่ง กด 📨 นำส่ง WMS ที่รายการนั้น → ป้าย Bus Status เปลี่ยนเป็น "ส่งแล้ว"
กด "บันทึก" อย่างเดียว คลัง ยังไม่เห็น — ต้องกด นำส่ง WMS ก่อน (ตั้งใจให้ตรวจก่อนส่ง)

ที่ WH13 (คลังสินค้า / QA)

  1. เปิด WH13 → เมนู รับเข้าสินค้า / QA → กดปุ่ม Auto Weighing → เห็นใบจาก V4 (เลขขึ้นต้น ROO / PRP)
  2. ติ๊กเลือกใบ (หรือบางรายการ) → กด นำเข้า → รายการขึ้นในฟอร์มรับเข้า
  3. ตรวจทุกแถว: เลือก ประเภทการตรวจรับ (ช่องขอบสีเหลือง — บังคับ) และใส่ BBF/EXP (วว/ดด/ปปปป) → กด ยืนยันการสร้าง RO report
  4. RO ไปรอ QA ตรวจ → QA ผ่าน → ยืนยันรับเข้าคลัง (ถ้าหน้าจอถาม login ใช้ QA-001 / 1234)
  5. เมนู ภาพรวมคลังสินค้า → คลัง WHRM → เปิด Stock Card → เห็นยอดเพิ่ม
B. QA สั่ง Hold ของ แล้วปลด Hold (QA Deviation ↔ WH13)
  1. เปิด QA Deviation → login (admin / 1234) → 1. Create New Deviation → เลือก Lot ที่มีของในคลัง (ค้นหาในคลัง)
  2. บันทึก → สั่ง Hold → WH13 ย้ายของไปคลัง WHSM06 (โซน Hold) อัตโนมัติ มีแจ้งเตือนที่ WH13 และเอกสาร DEV ในแท็บโอนย้าย
  3. ที่ WH13 ปุ่มตั้ง/ปลด Hold ใช้ไม่ได้แล้ว — ต้องทำที่ QA Deviation เท่านั้น (ตั้งใจ)
  4. ตรวจแก้เสร็จ → QA Deviation 3. Verification & Release → ปลด Hold → WH13 สถานะกลับเป็นปกติ และเตือนให้ย้ายของออกจาก WHSM06
C. ส่งสินค้าเข้าคลังด้วย FGT แล้ว QA อนุมัติ (WH13)
  1. WH13 → เบิกวัตถุดิบ/สินค้า → แท็บ 3. นำส่ง FGT
  2. เลือกคลังต้นทาง / ปลายทาง (ปลายทางได้แค่ WHC หรือ WHSM06), ผู้นำส่ง, ลูกค้า → กด 🔍 เลือกสินค้าจากสต็อก (แยก Lot)
  3. กดยืนยัน → login QA-001 / 1234 → ได้เลข FGT{วันเดือนปี}-0001 → ใบเข้าคิวรออนุมัติ
  4. เมนู FGT Approval → เปิดใบ → อนุมัติ (login QA-001 หรือ Tom ทุกครั้ง) → สต็อกต้นทางลด ปลายทางเพิ่ม
สต็อกไม่พอตอนอนุมัติ: ระบบถามว่าจะตัดเท่าที่มีไหม → สถานะ PARTIAL_STOCK
D. ฝ่ายขายสั่งสินค้า (BD02 → WH13)
  1. เปิด BD02 → 2. จัดการคำสั่งซื้อ (OMS) → เลือกสินค้าจากคลัง WHC (เห็นยอดจริง) → ใส่จำนวน → ยืนยัน (login BD001 / 2000) — ยอดถูกจองไว้
  2. WH13 → ศูนย์รับข้อมูล → เห็น SO ใหม่ → รับงาน
  3. WH13 → ศูนย์จ่ายออก (Dispatch) → อนุมัติ → ตัดสต็อก → BD02 ล้างการจองเอง
ตอนนี้: BD02 กับ WH13 ต้องเปิด ใน browser เดียวกัน SO ถึงจะไปถึง (ข้ามเครื่องยังไม่ได้) · เมนู "ศูนย์รับข้อมูล" ล็อกไว้ (🔒 DEV) — เปิดได้ด้วย Tom / 8888 ตามที่หน้าจอบอก
E. เพิ่ม / แก้รายการสินค้า (DBV2.0)
  1. เปิด DBV2.0 → 📋 Master → ค้นหาสินค้า → แก้ หรือ ✍️ Create Spec เพื่อเพิ่ม
  2. บันทึก → V4 และ WH13 ทุกเครื่องได้รายการใหม่ (หน้าที่เปิดค้างอยู่ให้รีเฟรช)
ปุ่ม Hard Reset ใน Settings มีผล เฉพาะเครื่องที่กด — ไม่ล้างรายการสินค้าของทุกเครื่อง

6. ป้ายสถานะมุมขวาล่าง

ป้ายความหมายต้องทำอะไร
● Server · ชื่อต่อกับระบบกลางแล้ว ข้อมูลส่งถึงเครื่องอื่นใช้งานได้เลย
● Server · รอส่ง 3กำลังส่งข้อมูลที่เพิ่งแก้รอ 1–2 วินาที
○ Offlineต่อระบบกลางไม่ได้ (เน็ต / server)ใช้ต่อได้ ข้อมูลส่งเองเมื่อกลับมา · ค้างนานแจ้งผู้ดูแล
⚠ พื้นที่เครื่องใกล้เต็มbrowser เครื่องนี้เก็บข้อมูลใกล้เต็มแจ้งผู้ดูแล · ลดการแนบรูป / ไฟล์ใหญ่
↻ โหลดข้อมูลจาก server ใหม่มีการล้างข้อมูลในเครื่อง ระบบดึงข้อมูลกลางกลับมารอหน้ารีโหลดเอง

7. ใช้ไม่ได้ ทำอย่างไร

อาการสาเหตุ / วิธีแก้
เปิดหน้าแล้วเด้งไปหน้า loginยังไม่ login หรือหมดอายุ (12 ชม.) → login ใหม่ ระบบพากลับหน้าเดิม
อีกเครื่องไม่เห็นข้อมูลที่เพิ่งทำดูป้ายทั้งสองเครื่องเป็นสีเขียวไหม · บางตารางต้อง รีเฟรช (F5) · ใบชั่งจาก V4 ต้องกด นำส่ง WMS ก่อน
รายการสินค้าใน dropdown มีน้อย / ไม่มีชื่อยังไม่มีใครเปิด DBV2.0 → เปิดหนึ่งครั้ง แล้วรีเฟรชหน้าเดิม
กดอนุมัติ / ส่ง แล้วถามรหัสเป็น login ชั้นที่ 2 ของหน้าจอ (ข้อ 3) — บางปุ่มถามทุกครั้ง
ไม่เห็นเมนู "ศูนย์รับข้อมูล" / มีป้าย 🔒 DEVฟีเจอร์ยังอยู่ในโหมดทดสอบ — เปิดด้วย Tom / 8888
กดเมนูแล้วขึ้น 404หน้านั้นทีมออกแบบยังไม่ส่งมา (เช่น เมนูลัดของ Preparing 8 รายการ, ลิงก์ Deviation ใน QA Incoming) — ใช้หน้าจากหน้ารวมแทน
หน้าจอดูแปลก / ปุ่มหาย หลังอัปเดตระบบกด Ctrl + F5 โหลดหน้าใหม่ทั้งหมด
